# OGQ 정산

정산 로우 데이터를 올리면 마켓별로 분류하고 수수료를 계산해 엑셀로 내려받는 웹앱입니다.

**사내 공유 URL: https://ogq-settlement.streamlit.app**

`main` 브랜치에 push하면 1~2분 뒤 자동으로 재배포됩니다.

로컬에서 돌리려면:

```bash
pip install -r requirements.txt
streamlit run app.py
```

정산 구분은 사이드바에서 고릅니다.

---

## 1. 네이버 출신 작가 정산

타 마켓 판매 로우 데이터 CSV → 마켓별 분류 → 네이버 수수료 계산 → 추합본 엑셀.

```
정산 대상 금액 = 판매액 - 결제 수수료 - 마켓 수수료
네이버 수수료  = 정산 대상 금액 × 15%
```

| 판매마켓 (CSV 값) | 결제 | 마켓 | 판매액 대비 실효율 | 추합본 | 시트 주기 |
|---|---|---|---|---|---|
| SOOP OGQ 마켓 | 5.5% | 14.175% | 12.04875% | SOOP | 월별 (판매월+1) |
| 채팅+ 원스토어 | – | 40% | 9% | RCS | 월별 (판매월+2) |
| 연합뉴스 | – | 40% | 9% | 연합 | 월별 (판매월+1) |
| 채팅+ OGQ 마켓 | 5.5% | 20% | 11.175% | 채팅플러스 | **분기별** |
| OGQ 그라폴리오 | 5.5% | – | 14.175% | 그라폴리오 | 월별 (판매월+1) |
| 네이버 밴드 | – | 30% | 10.5% | 밴드 | 월별 (판매월+2) |
| 프리미엄뉴스 | – | – | 15% | 프리미엄뉴스 | 월별 (판매월+2) |

- 기존 추합본 xlsx를 함께 올리면 파일 내용으로 마켓을 판별해 **맨 앞에 새 정산 시트를 추가**하고
  과거 시트와 서식은 그대로 둡니다.
- `B1 = SUM(I3:In) × 실효율`, 2행 헤더, 3행부터 데이터 — 기존 추합본과 동일.
- `REFUNDMENT`는 가격이 음수인 채로 SUM에 포함되어 자동 차감됩니다.
- 채팅+ OGQ마켓만 분기 시트 — 같은 분기 시트에 이어붙이며 거래 ID로 중복을 제거합니다.

터미널에서:

```bash
python3 make_fee.py <csv> [기존추합본디렉토리] -o <출력디렉토리>
```

## 2. SOOP 이모티콘 (스타즈 & 유니즈) 정산

**스타즈 파일 · 유니즈 파일을 각각 업로드**하면 계정 · 마켓별로 집계해
`요약 + 스타즈 + 유니즈` 시트를 가진 엑셀을 만들어 줍니다. 한쪽만 올려도 됩니다.

| 마켓 구분 | 기술 | 결제 | 마켓 | 크리에이터 |
|---|---|---|---|---|
| SOOP OGQ이모티콘 | 0% | 5.50% | 28.35% | 66.15% |
| NAVER OGQ마켓 | 0% | 7.70% | 27.70% | 64.60% |
| 채팅+ 원스토어마켓 | 0% | 0% | 58.00% | 42.00% |
| 채팅+ OGQ마켓 | 0% | 5.50% | 40.00% | 54.50% |

- 마켓 수수료는 **일반 크리에이터 요율의 2배**입니다 (SOOP 14.175% → 28.35%).
- 정지형 = `스티커`(단가 2,000원 고정), 동작형 = `애니메이션 스티커`(단가 3,000원 고정).
  **판매 개수 = 판매 금액 ÷ 단가** — 한 건에 여러 개를 살 수 있어 행 수와 다릅니다.
- 결제 수수료 = `ROUND(합계 × 결제율, 0)`, 마켓 수수료 = `ROUNDDOWN(합계 × 마켓율, 0)`,
  크리에이터 정산 금액 = 합계 − 결제 − 마켓.
- 부동소수점 오차로 ROUNDDOWN이 1원 어긋나는 케이스(42,000 × 0.2835)가 있어 전 계산을
  `Decimal`로 처리합니다.
- 필수 컬럼: `콘텐츠타입` · `판매마켓` · `판매금액`. 파일 안 시트 이름은 상관없습니다.
- **받는 엑셀의 요약 시트는 전부 수식입니다.** 로우 데이터를 고치면 요약이 따라 바뀝니다.
  - 판매 금액 = `SUMIFS(로우 시트)` / 판매 개수 = `금액 ÷ 단가`
  - 결제 = `ROUND(합계 × VLOOKUP(요율표), 0)`
  - 마켓 = `ROUNDDOWN(ROUND(합계 × VLOOKUP(요율표), 6), 0)`
  - 안쪽 `ROUND(...,6)`이 없으면 `42,000 × 0.2835`가 11906.9999…가 되어 11,906으로 잘립니다.

## 파일

| 파일 | 역할 |
|---|---|
| `app.py` | Streamlit 웹 UI (사이드바에서 정산 구분 선택) |
| `fee_core.py` | 네이버 출신 작가 정산 — 수수료율 · CSV 파싱 · 마켓 분류 · 시트 생성 |
| `stars_core.py` | 스타즈 & 유니즈 정산 — 요약 집계 · 요약 시트 생성 |
| `make_fee.py` | 네이버 출신 작가 정산 CLI |

수수료율은 각각 `fee_core.py`의 `MARKETS`, `stars_core.py`의 `MARKET_RATES` 한 곳에만 있습니다.
